# 服务端目录拆分与同名覆盖实施方案

## 目标

将服务端文件、状态和传输暂存数据分开配置，避免会话文件或内部状态出现在对外文件目录。网页上传遇到同名文件时，明确询问是否覆盖，并使用目标文件版本校验保护已有内容。

## 目录配置

目录配置统一放在 `server` 下。字段省略或留空时使用下列相对当前工作目录的默认值。

| 配置 | 默认值 | 内容 |
| --- | --- | --- |
| `server.files_dir` | `./files` | 对外提供的文件和子目录，也是上传完成后的发布根目录 |
| `server.states_dir` | `./okserver_states` | 会话元数据、锁、磁盘预算和文件摘要清单 |
| `server.cache_dir` | `./okserver_cache` | 上传分块和流式上传临时文件 |

三个目录须解析为互不重叠的绝对路径。状态和缓存目录不得位于 `files_dir` 内，防止内部数据被浏览或下载。服务端下载采用流式读取，目前不产生下载暂存文件。

建议的内部布局如下。

```text
files_dir/
  对外文件和子目录

states_dir/
  uploads/<会话ID>/metadata.json
  locks/*.lock
  budget/
  file-hashes.json

cache_dir/
  uploads/<会话ID>/payload.part
  streams/stream-*、multipart-*
```

上传恢复、过期清理、取消和磁盘空间统计须同时使用 `states_dir` 与 `cache_dir`。分块文件校验完成后发布到 `files_dir`。缓存与文件目录跨磁盘时，在目标目录创建临时文件并完成原子发布。

目标路径锁按完整目标路径散列命名并存放在 `states_dir/locks`。操作系统锁由打开的文件句柄持有，释放后留下的空锁文件不会继续占锁。保留目标锁文件可避免多个进程并发打开或删除时产生竞争。会话锁使用固定数量的分桶锁，避免每个会话永久新增锁文件；分桶碰撞会让无关会话短暂串行。流式暂存直接锁住暂存文件本身，避免每个请求留下锁文件。

## 配置切换与已有文件

不支持旧配置字段 `server.path` 和 `upload.chunk_dir`，服务启动时会提示新字段名称。保留旧版已发布文件时，将 `server.files_dir` 设置为原 `uploads` 目录；新建的状态和缓存目录可为空，文件摘要会按需重建。旧会话、锁和预算状态不迁移，因此未完成上传不能续传。

## 同名上传和覆盖

网页开始上传前，对 `/download/{path}` 发送 `HEAD` 并读取 ETag。文件不存在时正常上传。文件已存在时显示文件名并提供取消和覆盖选项。用户确认覆盖后，所有分片请求都携带 `?overwrite=true` 和该文件当前的 `If-Match`。

服务端继续以 `409` 拒绝普通同名上传，并增加稳定错误码 `destination_exists`，供网页区分目标冲突和会话冲突。覆盖时若目标 ETag 已变化，返回 `412`，网页刷新文件版本并再次询问。未获用户确认前不覆盖。新文件完整校验成功后才替换目标。

现有 API 路由和覆盖参数保持不变。调用方仍可通过 `HEAD /download/{path}` 获取 ETag，再以 `overwrite=true` 和 `If-Match` 请求显式覆盖。

## 实施步骤

1. 更新服务端配置结构、默认值、示例 YAML、路径解析校验和启动输出。
2. 拆分上传会话元数据与分块文件的存储路径，并调整恢复、清理、资源统计、锁、摘要清单、磁盘预算及流式上传暂存目录。
3. 为目标文件已存在的 API 响应增加错误码，保留原 HTTP 状态和请求格式。
4. 在网页上传流程加入文件版本预检、覆盖确认、条件请求和中英文提示。
5. 更新 README、配置示例和本方案的实施结果。

## 验收

- 空配置和显式空目录字段分别得到三个约定默认路径，自定义路径可以正常启动。
- 重叠目录配置被拒绝，服务状态和上传暂存数据不会落入对外文件目录。
- 分块上传、重启续传、取消、过期清理、摘要清单和磁盘预算在分离目录下工作。
- 缓存与文件目录跨磁盘时，校验成功后可以发布文件。
- 同名文件触发明确覆盖确认。取消或收到过期 ETag 的 `412` 时原文件保持不变。确认并校验通过后才完成替换。
- 针对配置、上传状态存储、发布冲突和网页确认流程运行对应测试。

## 实施结果

- 已将目录配置切换为 `server.files_dir`、`server.states_dir`、`server.cache_dir`，默认值和示例配置已更新。旧 `server.path` 与 `upload.chunk_dir` 会给出新字段提示；保留已发布文件只需让 `server.files_dir` 指向原文件目录，旧会话状态不迁移。
- 会话元数据、锁、磁盘预算和摘要清单写入状态目录；分块及流式上传暂存写入缓存目录。恢复、取消、过期清理、资源统计和发布流程已适配拆分后的路径。
- 目标路径锁仍按目标路径保留稳定锁文件；会话锁使用固定分桶，流式暂存锁直接锁住暂存文件，限制长期累积的锁文件数量。
- API 对未声明覆盖的同名请求返回 `409 destination_exists`；网页会先检查目标 ETag，再让用户确认覆盖，并用 `If-Match` 防止覆盖确认后目标被其他请求修改。
- README、中英文配置说明和原接入设计文档已同步更新。
